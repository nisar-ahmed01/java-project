# 🎓 Student Management System (Java OOP Project)

Student Management System using Java OOP — supports adding, viewing, searching, updating, and deleting student data along with attendance tracking.  
It also includes course management, enrollment, login system, and a modern dashboard-based UI.

## 📌 Purpose of the Project

The purpose of the Student Management System is to digitally manage and automate core academic activities such as student record handling, course management, enrollment, and attendance tracking in an educational institution.

Traditionally, academic records are maintained manually, which can lead to errors, duplication of data, and time consumption. This system solves these issues by providing a centralized, efficient, and user-friendly desktop application.

### 🎯 Objectives:
- Maintain accurate and structured student records  
- Automate attendance marking and tracking  
- Manage courses and student enrollments efficiently  
- Reduce manual paperwork and human errors  
- Provide quick and easy access to student information  
- Improve productivity for teachers and administrators  
- Offer a modern graphical user interface (GUI)  

Overall, the system improves the reliability, speed, and organization of academic management.

## 🧩 Main Modules

### 1. 🔐 Login and Registration Module
- User registration system for new users  
- Secure login authentication  
- Ensures only authorized access to the system  

---

### 2. 📊 Dashboard Module
- Main control panel after login  
- Central navigation hub for all modules  
- Provides quick access to system features  

---

### 3. 🎓 Student Management Module
- Add new students  
- View student details  
- Update student records  
- Delete student data  

---

### 4. 📚 Course Management Module
- Create and manage courses  
- View course details  
- Update or modify course information  

---

### 5. 🧾 Enrollment Module
- Enroll students into courses  
- View enrolled students  
- Manage and update enrollment records  

---

### 6. 📅 Attendance Management Module
- Mark student attendance (Present/Absent)  
- View attendance records  
- Track attendance per course  

---

### 7. 🖥️ User Interface (UI) Module
- Modern graphical interface using Java Swing  
- Includes panels, buttons, forms, and dialogs  
- Improves user experience and interaction  

---

### 8. ⚙️ Data Handling / Logic Module
- Handles system business logic  
- Validates input data  
- Connects UI with backend operations  

---

### 9. 🗄️ Database Module
- Stores all system data permanently  
- Includes students, courses, enrollments, and attendance

## ▶️ How to Run the Project

### 🔧 Requirements
- Java JDK 8 or above  
- IDE (NetBeans / IntelliJ IDEA / Eclipse)  
- MySQL Database Server  
- MySQL Connector JAR  

---

### 🚀 Steps to Run

#### 1. Import Project
- Open the project in your IDE  
- Set `src` folder as the source directory  

---

#### 2. Configure Database
- Start MySQL server  
- Create database (e.g., `student_db`)  
- Import required tables:
  - students  
  - courses  
  - enrollments  
  - attendance  
- Update JDBC connection in your project  

---

#### 3. Run Project
- Run the main class (e.g., `Main.java`)  
- Application will start with Login screen
